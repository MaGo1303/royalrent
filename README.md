## 📌 Descripción

RoyalRent es una aplicación web para consultar y contratar el alquiler de vehículos junto con servicios premium.

## 🎓 Estado

- **Proyecto académico:** Proyecto Fin de Ciclo (DAM) 2025.
- **Trabajo en equipo de 2 personas:** Gonzalo Velasco y Miguel José.
- Se publica con fines educativos y de portafolio; no es un producto comercial.

## ✨ Funcionalidades principales

- **Listado de vehículos:** catálogo de vehículos disponibles en la plataforma.
- **Reservas / alquiler:** proceso para solicitar el alquiler de un vehículo.
- **Servicios premium:** apartado de servicios premium asociados a la plataforma.

## 🚀 Cómo ejecutarlo

Requisitos: [Node.js](https://nodejs.org) y npm instalados. El repositorio está dividido en dos carpetas: `frontend` y `backend`.

```bash
# 1) Frontend (React + Vite)
cd frontend
npm install
npm run dev     # desarrollo con recarga en caliente
npm run build   # build de producción

# 2) Backend (Node.js + Express)
cd backend
npm install
npm start       # arranca el servidor
```
